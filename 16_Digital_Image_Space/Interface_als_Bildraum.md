# Interface als Bildraum

Tags: #interface #software-studies #postproduktion #workflow

## Kurzthese

Das Interface ist nicht nur Zugang zum Bild. Es ist selbst ein Bildraum, der Möglichkeiten, Aufmerksamkeit und Entscheidungen strukturiert.

## Relevante Interface-Räume

- Timeline.
- Node Graph.
- Layer Stack.
- Prompt Box.
- Viewport.
- Asset Browser.
- Review Space.
- Version Space.
- Parameter Panel.
- Gallery / Variation Grid.

## Warum das wichtig ist

AI-Postproduktion verteilt Gestaltung zwischen Prompting im Textfeld, Auswahl in Variantenrastern, Korrektur im Viewport, Compositing im Node Graph, Timing in der Timeline, Freigabe im Review-System und Dokumentation im Provenance Space.

## Anschluss an Theorie

- Manovich: Software als kulturelle Produktionslogik.
- Suchman: Handlung entsteht situativ am Interface.
- Chun: Interfaces erzeugen Gewohnheiten und Defaults.
- Binns: Interfaces schreiben sich als ästhetische Pfadabhängigkeit in Outputs ein.
